# Literature survey

- Moody, G. B. & Mark, R. G. (2001). The impact of the MIT-BIH Arrhythmia Database. *IEEE Engineering in Medicine and Biology Magazine*, 20(3), 45–50. The database provides a widely used benchmark for arrhythmia analysis.
- de Chazal, P., O'Dwyer, M. & Reilly, R. B. (2004). Automatic classification of heartbeats using ECG morphology and heartbeat interval features. *IEEE Transactions on Biomedical Engineering*, 51(7), 1196–1206. Demonstrates the value of morphology and interval features in heartbeat classification.
- The project uses the Kaggle ECG Heartbeat Categorization dataset (Shayan Fazeli), whose MIT-BIH split contains 187 normalized signal samples per beat and a categorical label. Random Forest is selected for robust nonlinear classification and interpretable feature importance.

This is a compact undergraduate survey; verify citation formatting and dataset license before publication.
